# Jaswik Ventures website redesign

Static website using HTML, CSS and JavaScript. No build step required.

## Files
- `index.html` — page structure/content
- `css/style.css` — main styles/design system
- `css/responsive.css` — responsive/mobile styles
- `js/script.js` — PCB estimator, enquiry form, WhatsApp, navigation and tank illustration animation
- `assets/jaswik-logo.svg` — extracted original logo
- `supabase/` — original enquiry backend files retained

## Run locally
Open `index.html` directly, or serve the folder with a local HTTP server.

## Deployment
Upload the contents of this folder to the existing static host. Keep the `supabase` folder and backend deployment separately as required.

The pricing configuration and enquiry endpoint/WhatsApp number remain in `js/script.js` near the top.
